Tiny module to support template usage


SETUP AND CONFIGURATION *tiny-templates.nvim-tiny.nvim-templates-support-setup-and-configuration-*

Setupwith Lazy

>lua
    return {
        "Coding4Glory/tiny-templates.nvim",
        -- defaults shown
        opts = {
            include = {
                vim.fs.joinpath(vim.fn.stdpath('config'), 'templates'),
                vim.fs.joinpath(vim.fn.stdpath('data'), 'lazy', 'tiny-templates.nvim', 'templates')
            },
            templates = {
                ['*.lua'] = 'skel.lua',
                ['ftplugin/*.vim'] = 'ftplugin.vim',
            }
        }
    }
<


USAGE                 *tiny-templates.nvim-tiny.nvim-templates-support-usage-*

Placeyour templates into the template directory, default on linux is
`~/.config/nvim/templates`.

Other Os place accordingly to `vim.fs.joinpath(vim.fn.stdpath('config'),
'templates')`
